**SpellBook** is an in-game overlay for managing & moderating Chivalry 2 servers & players.

## Installation

1. Open the **[latest SpellBook release](https://github.com/WizardOfTheVoid/Spellbook-frontend/releases/latest).**
2. Under **Assets**, download the file named `SpellBook-Setup-<version>.exe` and run it. Choose the `.exe` installer.
3. Sign in with Discord when SpellBook opens.
